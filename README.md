📊 Customer Shopping Behavior Analysis

📌 Overview
This project focuses on analyzing customer shopping behavior using real-world data.

The goal is to uncover insights related to purchasing patterns, customer segments, and product performance to support data-driven business decisions.

The project covers the complete data analytics lifecycle — from data loading and cleaning to analysis, visualization, and reporting.

📂 Dataset

Source: Customer Shopping Behavior Dataset

Format: CSV

Description:

Contains customer demographic details, purchase history, product categories, payment methods, and spending information.

🛠 Tools & Technologies

Python – Data loading, cleaning, and EDA

Pandas, NumPy – Data manipulation

Matplotlib, Seaborn – Data visualization

SQL (PostgreSQL / MySQL / SQL Server) – Querying and analysis

Power BI – Interactive dashboard creation

Gamma – Presentation (PPT) creation

🔄 Project Workflow

Data Loading

Imported the dataset into Python using Pandas.

Exploratory Data Analysis (EDA)

Analyzed distributions, trends, and relationships.

Identified missing values and inconsistencies.

Data Cleaning

Handled missing values and duplicates.

Corrected data types and standardized columns.

SQL Analysis

Loaded cleaned data into a relational database.

Executed SQL queries to extract business insights.

Dashboard Creation

Built an interactive Power BI dashboard.

Reporting

Created a professional report and presentation using Gamma.

Customer spending trends
